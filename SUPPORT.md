## Community Support (Questions & Discussions)

For usage questions, architectural discussions, and sharing ideas:

👉 **[GitHub Discussions](https://github.com/aeroforge-labs/PulsaRate-Go/discussions)**

Please use the appropriate category:
- **Q&A** — "How do I configure PID controller thresholds for my traffic pattern?"
- **Ideas** — "Would it be possible to support a sliding window algorithm?"
- **Show & Tell** — "Here's how I deployed PulsaRate-Go in our fintech API gateway"

> [!TIP]
> GitHub Discussions is the preferred support channel. Response times are faster and answers benefit the entire community.

## Bug Reports

If you've confirmed a bug (not a configuration question):

👉 **[Open a Bug Report](https://github.com/aeroforge-labs/PulsaRate-Go/issues/new?template=bug_report.yml)**

Please include:
- Go version (`go version`)
- PulsaRate-Go version / commit hash
- Minimal reproduction steps
- Observed vs. expected behavior
- Benchmark output if performance-related (`go test -bench=. -benchmem`)
